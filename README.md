# 🤖 Нагрузка системы — Telegram бот

Бот для мониторинга состояния вашей системы прямо из Telegram. Работает на Python и использует библиотеку [psutil](https://github.com/giampaolo/psutil) для сбора системной информации.

---

## ✨ Возможности

| Команда | Описание |
|---|---|
| `/cpu` | Текущая загрузка процессора |
| `/cores` | Нагрузка на каждое ядро отдельно |
| `/cpu_freq` | Текущая частота процессора (MHz) |
| `/memory` | Использование оперативной памяти (%) |
| `/free_memory` | Свободная оперативная память (%) |
| `/swap` | Использование файла подкачки |
| `/disk` | Использование дисковых разделов |
| `/uptime` | Время работы системы |
| `/network` | Сетевая активность (общая) |
| `/interfaces` | Сетевая активность по интерфейсам |
| `/battery` | Статус батареи (для ноутбуков) |
| `/sensors` | Температура датчиков (CPU и др.) |
| `/users` | Список авторизованных пользователей |
| `/processes` | Список запущенных процессов |
| `/system` | Комплексный отчёт о системе |
| `/help` | Список всех доступных команд |

---

## 📦 Установка

1. **Установите зависимости:**

   ```bash
   pip install telebot psutil
   ```

2. **Настройте токен бота:**

   Откройте файл [`config.py`](config.py) и вставьте свой токен от [@BotFather](https://t.me/BotFather):

   ```python
   token = "ВАШ_ТОКЕН_ЗДЕСЬ"
   ```

3. **Запустите бота:**

   ```bash
   python main.py
   ```

## 💻 Поддерживаемые платформы

Бот работает на **Windows**, **Linux** и **macOS**. Отдельные функции (например, `/battery` и `/sensors`) доступны только там, где соответствующее оборудование присутствует.

---

## ⚠️ Примечания

- Команда `/sensors` возвращает недостаточную информацию на системах без датчиков температуры — в этом случае бот сообщит, что данных нет.
- Команда `/processes` может выводить много текста; бот отправляет ответ частями, чтобы не превышать лимит Telegram.
- Некоторые разделы диска (например, оптические приводы) могут быть недоступны для чтения — такие разделы пропускаются.
